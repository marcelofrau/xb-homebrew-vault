## What's New in v2.0.4

### 🔄 Update Detection

- **Never auto-uninstall on update** — app no longer removes existing packages when updating; instead warns the user to check for duplicates and uninstall manually
- **Matcher false positive fix** — doom64ex and uhexen2 no longer match as gzdoom mods; tightened prefix guards (minimum 6 chars) and name ratio checks
- **Package name overrides** — "Doom64EX Classic" and "uHexen2" mapped to correct catalog entries via packageOverrides

### 🐛 Bug Fixes

- **Update hanging** — Xbox.IdleScreen (screensaver) blocking package manager no longer causes infinite wait; app auto-terminates blocking apps and uses size-based timeouts (2/5/10 min by file size)
- **Uploaded files renamed** — files uploaded via mobile file explorer no longer get prefixed with "xbvupload"; original filenames preserved
- **Log download 0-byte ZIP** — Android SAF content URI path issue fixed; logs now save correctly
- **Screenshot save 0-byte** — same SAF root cause, same fix via OpenWriteAsync
- **New folder not appearing in list** — mobile file explorer now refreshes after folder creation
- **Upload crash** — upload handlers now catch exceptions instead of crashing the app silently

### 📱 Mobile

- **Abort button on install/update** — Close button becomes "Abort" during active install; CancellationToken threaded through entire install chain
- **Adaptive Browse badges** — shows freshness (NEW/RECENTLY UPDATED) when disconnected; switches to update status (UPDATE AVAILABLE/UPDATED) when connected to Xbox
- **InstalledView package identity** — shows real PackageRelativeId when catalog name matches installed name (ambiguity hint)
- **LogsView button polish** — floppy disk icon, shorter labels (Save/Share), spacing between buttons

### 🧹 Code Quality

- **CancellationToken propagation** — install/update chain fully cancellable; 15 CA2016 warnings eliminated
- **Test updates** — PackageInstallService and InstalledView test fakes updated for new signatures
- **390/390 tests passing**
