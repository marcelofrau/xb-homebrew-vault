## What's New in v2.0.1

### 🔧 Safe Area + System Bars

- **Status bar icons fixed** — system bar colors now enforced via InsetsManager API, preventing Avalonia from overriding Android theme settings
- **Safe area padding** — content properly respects status bar and navigation bar insets
- **Smooth scrolling** — removed hover/touch highlight flash on cards and button scale animation during scroll
- **Back button navigation** — Android back button now navigates to previous tab before exiting the app

### 🐛 Bug Fixes

- **Title bar foreground** — removed incorrect `AutoSafeAreaPadding` on UserControl that was causing layout side effects

### 🏗️ CI/CD

- **Release notes template** — release body now sourced from `release-notes/v{version}.md` in the repo, preventing CI from overwriting manually curated notes
- **VirusTotal links** — scan results properly appended as collapsible section
