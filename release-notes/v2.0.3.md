## What's New in v2.0.3

### 🔄 Update Detection — Matcher Overhaul

Catalog-to-installed matching completely rewritten with 10+ strategies, replacing the old prefix-only approach:

- **Alphanumeric normalization** — matches "Super Mario Bros Remastered" vs "SuperMarioBrosRemastered" (spaces/special chars stripped)
- **Prefix matching** — "Dolphin" matches "Dolphin Emulator", "ScummVM" matches "ScummVM UWP Frontend"
- **PFN / FullName matching** — uses PackageFamilyName and PackageFullName as additional matching signals
- **Download URL matching** — filename word containment + token prefix (e.g. "SRB2" matches download token "SRB2SDL2")
- **Suffix stripping** — removes common UWP/Frontend/PC suffixes before rechecking
- **Override priority** — manual `package-overrides.json` mappings bypass algorithmic matching entirely, preventing false positives
- **False positive prevention** — directional prefix checks, minimum display name length guards, strict ID length rules

### 🐛 Bug Fixes

- **Xbox WDP upload format** — manual multipart body construction matching browser format; fixes 400 "Missing .msix" errors
- **Large file OOM** — all file uploads now stream from disk via `StreamContent` / `ConcatStream` instead of loading into memory
- **Sideload dependency refresh** — dependency list updates when new deps are added in sideload wizard
- **Portal download failures** — improved error handling for indirect share links (GoFile, Google Drive, OneDrive)
- **Install verification** — better post-install state checking

### 📱 Mobile

- **Save Log button** — logs screen now has a button to save current log to file
- **Sideload wizard dependency fix** — dependency list refreshes properly when packages are added

### 🧹 Code Quality

- **6 compiler warnings eliminated** — CA1844, CA1861, CA1835, CS8604
- **48 unit tests** — comprehensive matcher coverage for all 10+ strategies, real-world scenarios (Dolphin, Sonic, CVR, ScummVM, SRB2, Castlevania, FlashBack, etc.), false positive regression tests
