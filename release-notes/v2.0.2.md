## What's New in v2.0.2

### 🐛 Bug Fixes

- **X-Files / sideload install false failures** — package manager now retries when Xbox reports resource-in-use (`0x80073D02`) instead of immediately failing; Xbox typically releases DevHome/XboxDevices locks within 10-20s
- **Large package upload crash (OOM)** — sideload uploads now stream files from disk via `StreamContent` instead of loading entire package into memory; fixes OOM crash on Android for packages >200MB (e.g. 574MB appx)
- **Screenshot intermittent failure** — screenshot capture retries up to 5 times with 1s delay before reporting failure; Xbox WDP occasionally returns HTTP 500 transiently
