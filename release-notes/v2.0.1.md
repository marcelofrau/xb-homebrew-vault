## What's New in v2.0.1

### 🔧 Safe Area + System Bars

- **Status bar icons** — white icons on Android via `RequestedThemeVariant="Dark"`, respecting the framework's `SystemBarTheme` path
- **Safe area padding** — content respects status bar and navigation bar insets; auto-detects edge-to-edge on Android 15+ and gracefully falls back on older devices
- **First-frame flash fix** — AXAML fallback margins prevent momentary overlap before `OnLoaded` fires
- **Smooth scrolling** — removed hover/touch highlight flash on cards and button scale animation during scroll

### 📦 Sideload Improvements

- **Connection guard** — sideload wizard now checks console connection before opening; opens connection overlay if disconnected
- **URL resolver** — indirect share links from GoFile, Google Drive, and OneDrive are automatically resolved and downloaded for sideload
- **SAF file picker fix** — Android content:// URIs now properly copied to temp files instead of silently failing
- **Local file display** — selected files show the original filename instead of `sideload-<hash>`
- **Back during analysis** — pressing back while analyzing dependencies cancels the operation cleanly instead of leaving an infinite spinner
- **Wizard step images** — sideload wizard breadcrumb indicators now use correct `custominstall-step*` icons instead of setup wizard images
- **Done button** — enabled only on install success (not during summary state)
- **Installing animation** — static image replaced with spinning CdSpinner during package install

### 🔄 Update Detection

- **Version overrides** — `package-overrides.json` supports catalog-version-gated `versionOverrides` to map catalog versions to actual Xbox manifest versions, eliminating false update positives (e.g. Sonic 2 SMS `2.9.2` → `2.9.0.2`, Safe Exit `1.0.0.1` → `1.0.0.0`)

### 🐛 Bug Fixes

- **Android back button** — navigates back through tab history and overlays; only exits the app when on Browse with empty history
- **Installed tab dropdown** — flyout closes on item tap via `Dispatcher.UIThread.Post(Background)` to avoid suppressing the command binding
- **Uninstalling overlay** — horizontal spinner layout with status text
- **Setup wizard bokeh** — hero background flush under TitleBar with no gray gap; content centered vertically

### 🏗️ CI/CD

- **Release notes template** — release body sourced from `release-notes/v{version}.md`, preventing CI from overwriting manually curated notes
- **VirusTotal links** — scan results properly appended as collapsible section

### 🧹 Code Quality

- **11 build warnings eliminated** — CA1707, CA1822, CA1001, CA1816, CA1861, CS0067, CS8601/CS8602/CS8625
- **URL resolver tests** — 20+ new tests for URL resolution patterns and version override logic
- **Safe area tests** — version-aware padding behavior verified on both Android 11 and Android 15+
