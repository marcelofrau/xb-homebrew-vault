## What's New in v2.0.3

### 🐛 Bug Fixes

- **Catalog false-positive matches** — six-layer matching defense prevents incorrect update candidates (HeXen↔uHexen2, Doom64EX↔GZDoom, Castlevania:LoD↔Castlevania Revamped, Gen1Recomp↔FlashBack "UWP", Zelda 64 Recompiled↔Gen1Recomp, Ship of Harkinian↔"uwp" prefix)
- **Portal downloads create 0-byte files** — Android downloads via SAF now correctly populate the destination URI (was skipping `PostDownloadSaveAsync`)
- **Android uploads silently fail** — SAF URIs are now copied to temp files before upload when `TryGetLocalPath` returns null
- **App updates install as duplicates** — pre-install conflict detection auto-uninstalls packages with different PackageFamilyName before installing
- **Install reported as failed when Xbox installed async** — after timeout, waits 15s then checks if package actually appeared in installed list
- **Connect button crashes on ErrorDialog** — threading fix removes `Task.Run` wrapper that created UI elements from background threads
