## What's New in v2.0.5

### 🧩 Matching & Overrides

- **Mature catalog override table** — `package-overrides.json` rebuilt via a full package sweep; the matcher now resolves catalog↔installed identity mismatches across the whole catalog
- **Local override auto-recorded** — installing a package whose identity differs from the catalog now auto-records a local override, so future matches use the real PackageFamilyName instead of a stale catalog entry
- **Item detail from installed card** — clicking an installed card opens the item detail overlay/window (reinstall + uninstall in installed mode)

### 🔄 Updates

- **Update check on startup** — the `CheckForUpdatesOnStartup` setting is now honored (default on)
- **Download button on update dialog** — "update available" dialog (desktop + mobile) now has a **Download** button that opens the release URL to fetch the newest build

### 📦 Installation & Sideload

- **Sideload wizard hardening** — success hero de-duplicated, oversized install hero fixed, "close all" overlay no longer double-pops, step-3 main package name + dependency diagnostics now correctly logged
- **Source file validation** — custom install now rejects unsupported file types (e.g. `.iso`) at browse/analyze time with a clear message; **Analyze Package** and **Next** stay disabled until a valid package (`.appx`/`.msix`/`.appxbundle`/`.msixbundle`/`.zip`) or folder is picked. Unknown extensions are filtered up front; already-supported extensions continue to the analysis step

### ⚡ Transfers

- **Large transfer no longer times out** — uploads/downloads use a dedicated infinite-timeout client with per-request cancellation caps instead of dying on the blanket 30s HTTP timeout
- **Portal folder download as ZIP** — downloading a portal folder now bundles it as a ZIP (fixes Android SAF multi-file transfer)

### 🖥️ System Info

- **Redesigned against the WDP contract** — System, Network, Process and Performance panels rebuilt for the real Device Portal API (desktop + mobile), backed by full domain tests

### 🔒 Security

- **SEC2 AES-256-GCM secrets** — credentials now encrypted with managed AES-256-GCM (machine-bound key, no P/Invoke), replacing legacy XOR; same behavior on Windows/macOS/Linux/Android
- **URL centralization** — all app/service URLs consolidated in `AppUrls`

### 🐛 Reinstall & Data

- **Reinstall preserves app data** — reinstalling no longer uninstalls first (which wiped the app's `LocalState`); it installs over the existing package and keeps local data. Confirmation messages updated on desktop + mobile
- **Bundle installs verified correctly** — `.msixbundle` installs no longer report a false `FAILED` verdict; the verify step now reads the bundle identity from `AppxBundleManifest.xml` (e.g. `jazz2.resurrection`) instead of falling back to the filename

### 🧹 Code Quality

- **Composition root extraction** — app wiring moved into `AppServices`, split per-platform into `DesktopUiActions` / `MobileUiActions` (App.axaml.cs went from ~1,693 to ~376 lines)
- **`async void` eliminated** — all handlers converted to `FireAndForget` with context logging; view models implement `IDisposable`
- **751/751 tests passing** (desktop + Android build clean)
